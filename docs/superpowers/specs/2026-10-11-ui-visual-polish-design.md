# UI 优化第②批：视觉观感打磨 — 设计 Spec

- **日期：** 2026-10-11
- **状态：** 待用户复审（复审通过前禁止开发）
- **计划分支：** `feature/ui-visual-polish`（Git Flow，spec 与实现同分支）
- **路线图定位：** 「整体界面优化」三批的第②批；地基为已合入的第①批令牌体系（`6def4d2`），③布局 IA + 交互一致性随后

## 1. 背景与目标

第①批把全部颜色收敛为语义令牌并交付暗色主题，但**版式语言仍是离散的**：`styles.css` 有 14 种字号（10px×48、11px×41、12px×43 相邻三档混用 130+ 处，9/25/26px 孤值散落）、8 种圆角（5/7/8/10/12px 五个近似值并存）、间距无栅格节奏（10px 12px、22px、17px、9px 等任意值）。本批建立**字阶/间距/圆角/阴影四类版式令牌**并全站归并，辅以四族组件精修，让整体「齐」且类型更密。

**已裁定决策（2026-10-11 用户确认，视觉伴侣小样选型）：**

1. **方向 = A 的密度 + B 的字阶**：留白/间距/圆角保持当前舒适档（落 4px 栅格），字阶整体下移到 B 的密排档（11/12/14/18/24）——类型更紧凑、版面呼吸感不变。
2. 四族组件精修**全选**：数据表格、表单控件、按钮体系、卡片与标题层级。
3. 全站生效（8 视图浅暗两套同构）——字阶/间距/圆角主题无关，令牌化后自动双主题一致。
4. 深浅两套均以 playwright 前后截图对比验收（第①批已实证可行）。

## 2. 非目标

- 布局结构、导航组织、信息取舍调整（第③批内容）。
- 设计语言更换（不换字体族、不改品牌色、不换风格基调）。
- 交互行为改造（加载/空态/toast 行为、操作流——第③批内容；本批只统一其视觉尺寸与间距）。
- `.vue` 组件文件结构重构、styles.css 拆分（维持单文件）。
- 后端改动（零）。

## 3. 字阶令牌（14 种 → 5 档）

`:root` 新增（主题无关，dark 块不覆盖）：

| 令牌 | 值 | 吸收现有字号（styles.css 实测分布） |
|---|---|---|
| `--fs-xs` | 11px | 9px×2、10px×48、11px×41（约 91 处；10→11 微增 1px，服务 B 档密排的可读下限） |
| `--fs-sm` | 12px | 12px×43、13px×20（表格/正文主档，13→12 收密） |
| `--fs-md` | 14px | 14px×1、15px×2、16px×5（卡片/区块标题） |
| `--fs-lg` | 18px | 18px×2、19px×1、20px×5、22px×1（指标数字/视图大标题，-2px） |
| `--fs-xl` | 24px | 25px×1、26px×1（顶栏品牌级大字） |

合计约 134 处声明全量替换为 `var(--fs-*)`；`.vue`/`.ts` 无硬编码 font-size（已核实），无需触碰。

## 4. 间距 / 圆角 / 阴影令牌

**间距 `--space-1..6`（4/8/12/16/20/24）**：styles.css 全部 padding/margin/gap 的像素值落 4px 栅格，最近取整、平局向下（10→8、17→16、22→24、9→8、6→4）。**全站版面产生 ±1-2px 细微位移——这是本批打磨的实质，属预期**。允许的字面量残留：`0`、`1px`（边框）、`2px`（微调）、`999px`/`50%`（形状）、`auto`。替换后消费一律 `var(--space-N)`，组合值（如 `8px 12px` → `var(--space-2) var(--space-3)`）。

**圆角三档 + 特例**：

| 令牌 | 值 | 吸收 |
|---|---|---|
| `--radius-sm` | 6px | 5px×7（+1px） |
| `--radius-md` | 8px | 7px×8、8px×17、10px 中控件类 |
| `--radius-lg` | 12px | 10px 中卡片类、12px×4 |
| 特例保留 | 999px / 50% | 药丸 chip / 圆点 |

旧 `--radius`(12px)/`--radius-small`(8px) 两令牌在消费迁移完成后**删除**（grep 断言无 `var(--radius)`/`var(--radius-small)` 残留）；新名与旧值兼容：原 `var(--radius-small)` 消费点 → `--radius-md`，原 `var(--radius)` 消费点 → `--radius-lg`。

**阴影两档 + 特例**：`--shadow-sm`（吸收现 `--shadow-small` 0 5px 16px 与 `--shadow-hairline` 0 1px 3px——按用途就近归并，若两类用途差异大则保留 `--shadow-hairline` 为特例并在计划申报）、`--shadow-md`（吸收现 `--shadow` 0 14px 34px）；`--knob-shadow` 与 `0 0 0 3px var(--glow-*)` 焦点环保留（非视觉打磨对象）。旧 `--shadow`/`--shadow-small` 迁移后删除。

## 5. 四族组件精修（规则级，具体 CSS 行在计划逐条落地）

1. **数据表格**：tbody 行内边距统一 `var(--space-2) var(--space-3)`（≈34px 行高 @ `--fs-sm`）；表头、斑马纹、悬停态（`--row-hover`）、可点击行、分页器内边距统一；`.data-table` 家族内不再有 9/10/13px 混排。
2. **表单控件**：`input/select/.number-input` 高度统一 32px；focus 态统一 `0 0 0 3px var(--focus-ring)`；单位后缀（元/BP/%）基线对齐；`.field` 标签与控件间距栅格化。
3. **按钮体系**：三档高度——`sm` 28px（text-button/icon-button）、`md` 34px（.button/.button-secondary/.button-primary 默认）、`lg` 38px（面板主操作）；图标与文字 `gap: var(--space-2)` 垂直居中；禁用态统一 `opacity` 与 `cursor`。
4. **卡片与标题层级**：`.surface` 内边距栅格化（16/20）；`.surface-heading` 三段（section-kicker / 标题 / 状态位）统一垂直节奏与间距；`.heading-note`、`.section-kicker` 字阶映射 `--fs-xs`。

精修原则：**只动尺寸/间距/字阶/圆角/阴影，不动颜色与结构**；每条规则调整前后行为可由截图对比核验。

## 6. 实现方式

- 全部走 CSS 令牌（`:root` 追加字阶/间距/圆角/阴影令牌，主题无关不进 dark 块）；styles.css 全量替换 + 按第 5 节清单做规则级精修。
- 替换顺序：先令牌定义追加 → 字号全量替换 → 间距全量替换 → 圆角/阴影迁移（含旧令牌删除）→ 四族精修。每步可独立验证，避免一次巨 diff。
- **before 截图在实现计划 Task 1 采集**（playwright 8 视图 × 浅/深，存 SDD workspace），验收时与 after 对比。

## 7. 机械验收（grep 断言）

- 字号：styles.css 中 `font-size: \d` 像素字面量为 **0**；`var(--fs-*)` 恰 5 种。
- 圆角：`border-radius` 像素字面量为 0（`999px`/`50%` 除外）；`var(--radius-sm|md|lg)` 三种 + 特例。
- 阴影：`var(--shadow)`/`var(--shadow-small)` 旧名残留为 0。
- 间距：padding/margin/gap 像素值全部 ∈ {0,1,2} ∪ {4 的倍数} ∪ {auto,999px,50%}（awk 核算，命令在计划给出并预验证）。
- 深浅同构：字阶/间距/圆角/阴影令牌不进 dark 块（自动同构），dark 块行数不变。

## 9. 已知限制（如实披露）

- 版面 ±1-2px 位移与字号 ±1px 变化是本批的**目的**而非副作用——「观感更齐」必然伴随微小变化；逐像素与改前一致不可能同时满足「打磨」。
- 表格行高收密后单屏信息量略增；若某些长文本列出现换行变化，以截图对比逐处核验，断裂性换行属于精修清单内必须修复项。
- 字阶 5 档是密排方向（B 档）；若使用中发现可读性问题（如 11px 中文偏小），个别档位可在令牌层单独回调（改一处生效全站）。
