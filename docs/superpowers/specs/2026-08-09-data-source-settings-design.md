# 多数据源与网站设置设计

## 目标

提供一个可持久化的网站设置页面，让用户管理工作台基础参数和行情数据源；支持腾讯公开行情、AkShare、Tushare 三种来源，并在来源不可用时按优先级自动切换。

## 配置菜单

在侧边栏增加“设置”入口，包含三个标签页：

1. 工作台：工作区名称、默认账户资金、默认盯盘开关。
2. 数据获取：实时行情、历史日线、选股指标分别选择首选来源；开关自动故障切换；设置刷新间隔、缓存时长、请求超时与重试次数。
3. 连接状态：展示每个来源是否可用、最后成功时间、失败原因和当前环境中是否检测到 Tushare Token。

## 数据源适配层

### 统一契约

后端为每类数据定义稳定的返回结构：

- 实时行情：报价、指数、来源名、获取时间、错误列表。
- 历史日线：统一日期、开高低收、成交量和成交额字段。
- 选股指标：复用现有候选池行结构。

每个来源适配器只负责将上游数据映射为该结构。路由、网格策略和定时回测继续调用统一的 `load_market`、`load_history`、`load_screener` 接口。

### 来源能力

- 腾讯公开行情：默认实时行情、指数、复权日线和候选池；无需密钥。
- AkShare：历史日线和选股指标备选；无密钥。未安装依赖或上游异常时返回可诊断的来源错误。
- Tushare：历史日线和选股指标备选；Token 来自服务器 `TUSHARE_TOKEN` 环境变量。无 Token 时不可选择为首选来源，但可显示配置提示。

### 选择与故障切换

- 每类数据使用各自的首选来源，默认全部为腾讯。
- 首选来源失败且启用自动切换时，按照固定顺序尝试剩余可用来源；响应中标注实际来源与失败原因。
- 不混合一份响应中的来源；一次请求只使用一个成功来源，便于回测溯源。

## 持久化与安全

- 非敏感设置以工作区维度保存到 PostgreSQL，浏览器本地存储作为离线回退。
- 不在设置页面输入、保存或返回任何 API 密钥、数据库密码或 Redis 密码。
- `TUSHARE_TOKEN` 仅从服务器环境变量读取；健康检查和设置接口只返回布尔可用状态。
- 市场日线快照记录实际来源，确保后续网格回测可追溯。

## 接口

- `GET /api/settings`：返回工作台设置、来源能力和当前状态，不返回密钥。
- `PUT /api/settings`：校验并保存非敏感工作区设置。
- `POST /api/settings/data-sources/{source}/test`：对指定来源执行不带密钥回显的连接测试，返回状态与诊断信息。
- 现有市场、历史、选股和网格接口读取当前工作区的数据配置；未配置时保持腾讯来源的现有行为。

## 验证

- 对来源选择、无 Token 的 Tushare 校验、故障切换和来源标记编写后端测试。
- 验证设置接口不包含 Token 或数据库/Redis 连接信息。
- 在浏览器验证设置保存、连接测试、来源状态和窄屏布局。
